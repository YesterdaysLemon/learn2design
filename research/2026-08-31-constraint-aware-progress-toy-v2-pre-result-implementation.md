1. bootstrap chronology, framing, network denial, Windows Job containment,
   descendants, output sealing, and cleanup;

3. scientific translation, oracle separation, byte preimages, and exclusion of

scientific projection on an exactly matching host; the real network and

could release the lease; prior completion receipts and outer worker receipts

issue was repaired before the source hashes were frozen. All three final audits
returned clean verdicts with no remaining substantive blocker.
