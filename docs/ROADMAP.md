# Roadmap

1. Reproduce the official baseline and its packaging contract.
2. Build deterministic local evaluation with explicit budgets and seeds.
3. Compare a small number of well-motivated optimizer families.
4. Live-test one exact-semantic archive-median start; the first topology-conditioned neural and nearest-neighbor screens did not pass their offline gates.
5. Generate and validate a minimal submission bundle from a tagged revision.

The plan will change when measurements justify it. Leaderboard performance and local validation will remain separate claims.
